# OSam

用說的就能用的個人秘書。你講話，它記事情、整理想法、記健康紀錄；畫面只負責呈現。

部署在**你自己的** Claude 帳號（私人 Artifact），資料只有你看得到，用的是你自己的 Claude 方案。

## 部署

需要 Claude 付費方案（Pro 或 Max）和 Claude Code。在 Claude Code 打開這個 repo，說：

> 幫我部署這個到 Artifact

Claude 會照 `CLAUDE.md` 完成，最後給你網址。用手機的 Claude App 打開，第一次說話時按允許。

想讓它能上網查資料，先在 claude.ai「設定 → 連接器」連上 Parallel Search。

## 更新

repo 有新版時，同樣說「幫我部署這個到 Artifact」，會更新你原本那個，資料不會不見。
