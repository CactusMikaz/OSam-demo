# OSam

用說的就能用的個人秘書。你講話，它記事情、整理想法、記健康紀錄；畫面只負責呈現。

部署在**你自己的** Claude 帳號（私人 Artifact），資料只有你看得到，用的是你自己的 Claude 方案。

## 部署

需要 Claude 付費方案（Pro 或 Max）和 Claude Code。在 Claude Code 打開這個 repo，說：

> 幫我部署這個到 Artifact

Claude 會照 `CLAUDE.md` 完成，最後給你網址。用手機的 Claude App 打開，第一次說話時按允許。

想讓它能上網查資料，先在 claude.ai「設定 → 連接器」連上 Parallel Search。

## 更新

repo 有新版時，說「幫我更新 OSam」（或同樣說「幫我部署這個到 Artifact」），會更新你原本那個，資料不會不見。

## 版本

### 2026.10.13

- **助理變總機**：跟助理說的事如果歸別頁管（例如報體重），它會直接轉給那一頁記好；只是提到的，它會給你一張卡片，點了就過去
- **每個 Agent 都能上網**：助理和每一頁都能請背景去網路上查資料（要先連 Parallel Search）
- **傳照片**：輸入列多了圖片按鈕，可以把照片傳給任何一頁的 Agent 看
- **頁面上鎖**：設定裡可以把任何一頁加上 4 位數密碼；上鎖頁面的內容，其他頁的 Agent 碰不到。側板會顯示哪些頁面上鎖、哪些已解開，點打開的鎖就重新鎖上
- **電話和網址點了就能用**：回覆和待辦裡的電話點了就撥、網址點了就開
- **健康頁當教練**：可以請它排每週課表
- **待辦記得時間**：記下每件事什麼時候建立、什麼時候做完，可以問「我昨天做了什麼」；整個清單都做完會自動封存
- **朗讀聲音**：設定裡可以選男聲或女聲
- **回答更快也更準**：記錄類的回覆用快的設定，查資料和整理記憶用最強的模型
- 修正：健康頁的 Agent 會一直「連線出了問題」；送出失敗時提示會馬上消失
