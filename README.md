# OSam

用說的就能用的個人秘書。你講話，它記事情、整理想法、記健康紀錄，也能跟朋友的 OSam 交換名片、寄資料；畫面只負責呈現。

部署在**你自己的** Claude 帳號（私人 Artifact），資料只有你看得到，用的是你自己的 Claude 方案。

## 部署

需要 Claude 付費方案（Pro 或 Max）和 Claude Code。在 Claude Code 打開這個 repo，說：

> 幫我部署這個到 Artifact

Claude 會照 `CLAUDE.md` 完成，最後給你網址。用手機的 Claude App 打開，第一次說話時按允許。

想讓它能上網查資料，先在 claude.ai「設定 → 連接器」連上 Parallel Search。

## 更新

repo 有新版時，說「幫我更新 OSam」（或同樣說「幫我部署這個到 Artifact」），會更新你原本那個，資料不會不見。

## 版本

### 2026.10.13.5

- **開場動畫**：打開 OSam 時，「OS」旁邊的 am／pm 像計數器一樣跳兩下，停在 am、跟 OS 碰在一起變成「OSam」，再往遠處退去、淡出。OS 是作業系統，am 暗示它全天候都在
- **可以跳過開場**：在意效率的話，到設定 →「畫面」→「開場動畫」選「跳過」，打開就直接進畫面；手機和電腦會同步
- **背景查資料看得到**：請 OSam 上網查資料時，摘要上方會出現一個小標籤，告訴你它還在背景查

### 2026.10.13.4

- **拍名片的 QR Code 更好讀**：拍另一支手機螢幕上的 QR Code（交換名片、對方回傳名片）比較讀得出來了；讀不到時會告訴你怎麼重拍，不會再默默變成一張附件照片
- **Android 加照片和檔案要用 Chrome**：Android 的 Claude App 目前叫不出選檔畫面。用手機的 Chrome 打開你的 OSam 網址（先登入 claude.ai）就能加照片，可以在 Chrome 選單按「加到主畫面」；在 App 裡按「＋」沒反應時，OSam 也會提醒你
- 小提醒：如果畫面整個變得很小，看一下 Chrome 選單的「電腦版網站」是不是被勾起來了

### 2026.10.13.3

- **Android 傳照片**：修正 Android 手機按「＋」沒反應、選不了照片的問題；手機相機拍的大照片會自動縮小再傳，不會再說「這張圖太大了」
- 如果 Android 上按「＋」還是沒反應，可以改用手機的 Chrome 打開你的 OSam 網址（先登入 claude.ai），再用「加到主畫面」

### 2026.10.13.2

- **新頁面：傳真機**：跟朋友的 OSam 往來
  - **交換名片**：選你的名片按「QR Code」，名片翻到背面讓對方拍；不在身邊就按「發送」用 LINE 傳。收下名片時會有像 iPhone 碰一下交換聯絡人的動畫
  - **寫信寄資料**：說「寫一封信給阿珠，附這週的待辦」，OSam 先打草稿，你看過按「封口」才會寄。對方寄來要你填的表格，可以按「照這份回填」
  - **收到的東西先讀過**：OSam 會先幫你看一遍、寫一段摘要，裡面有可疑的文字會用紅字標出來
  - 內容都會加密，只有收件人的 OSam 打得開。網路上交換名片有風險，最好跟見過面的人當面交換
  - 試用版：一張名片、主動交換最多 10 位，收別人的名片不限
- **固定要做的事**：從想法交辦「每週運動三次」這類的事，助理會問你多久一次、每次多久、做到什麼時候，幫你記成例行事項
- **語氣更像助理**：回答更簡短直接，不撒嬌、不說想你
- **別人的私事不記**：只記你需要的（例如貓的獸醫是誰），不記朋友的私事；很私人的頁面會建議你上鎖
- **使用說明和求助專線**：第一次打開會先看到使用說明；聊到很難受的事時，OSam 會給你求助專線
- **開場問題**：想法頁的開場問題換了一批；設定裡可以讓它深夜不問，或整個關掉
- **設定重新整理**：照影響的範圍分組，比較好找

### 2026.10.13

- **助理變總機**：跟助理說的事如果歸別頁管（例如報體重），它會直接轉給那一頁記好；只是提到的，它會給你一張卡片，點了就過去
- **每個 Agent 都能上網**：助理和每一頁都能請背景去網路上查資料（要先連 Parallel Search）
- **傳照片**：輸入列多了圖片按鈕，可以把照片傳給任何一頁的 Agent 看
- **頁面上鎖**：設定裡可以把任何一頁加上 4 位數密碼；上鎖頁面的內容，其他頁的 Agent 碰不到。側板會顯示哪些頁面上鎖、哪些已解開，點打開的鎖就重新鎖上
- **電話和網址點了就能用**：回覆和待辦裡的電話點了就撥、網址點了就開
- **健康頁當教練**：可以請它排每週課表
- **待辦記得時間**：記下每件事什麼時候建立、什麼時候做完，可以問「我昨天做了什麼」；整個清單都做完會自動封存
- **朗讀聲音**：設定裡可以選男聲或女聲
- **回答更快也更準**：記錄類的回覆用快的設定，查資料和整理記憶用最強的模型
- 修正：健康頁的 Agent 會一直「連線出了問題」；送出失敗時提示會馬上消失
